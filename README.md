# faust-vn

A playable visual-novel prototype of the opening of Goethe's *Faust* (Part I), in
Teodoro Llorente's public-domain Spanish translation — and `vnpipe`, the reusable
pipeline that builds it: Gutenberg text → annotated JSON → Ren'Py project.

The game is in Spanish. Art is AI-generated (see [docs/licensing.md](docs/licensing.md)).

## Quick start

```bash
uv sync
uv run vnpipe --help
```

Run instructions for the game: [docs/running.md](docs/running.md).
Pipeline overview: [docs/plan.md](docs/plan.md).
